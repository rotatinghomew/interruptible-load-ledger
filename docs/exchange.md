# 厂区计量和响应单据
时段左闭右开，时间带时区，协作和计量按整分钟处理。功率以整数 kW 表示，基线和观测均为该分钟平均功率，不允许用别的日子估补。每分钟响应的基准为冻结基线减正式观测，负值按零。证据修订以计量方序号和指向原记录的 revises 识别；同一序号同一内容可以重收。
邀约 `target_kw` 是每分钟合计所需值；`latest_reply` 是对外接受前的答复截止。厂合同的 daily_kw_minutes 是功率和承诺时长乘积的当日上限。离场厂提前认定不能交付的批次记录，与之后收到的原承诺版本分开。交接以离场厂和接手厂都确认的交界为准，不能早于已生效离场通知记录时间。只要合同允许且总承接未过厂的 min/notice/可用功率约束，一个厂可在同分钟对多个邀约承担不同份额。
同一总表下多项承诺并行，降低量先按计量方明确归属供电回路及该分钟仍有效的份额认定。一项不能超出承接功率。未标回路的余量按未达到的承接功率比例在同表有效承诺间分摊，以承接编号排序消除整千瓦余数并保持总量。价格用分/千瓦分钟，合同记录每个经认可的千瓦分钟的合同价，实量更正采用同价，已签发账项只可附调整。
## 资料发布
报文样例位于 `data/`，每个集合是一个 UTF-8 JSON 数组，id 是集合内的来源标识。跨集合引用使用原标识。没有值的可选项可以不提供，JSON null 表示已报告但暂未确认的值。
